\chapter{明園樓盤一覽}

為了避免讀者們不慎入住李松堅和凌菲菲的明園集團的樓盤，這裏列出明園集團的樓盤，以供參考。

\ 

謹記：{\Large\textbf{住明園樓盤，享綠帽人生。}}

\newpage

\section{汕頭海灣一號}

\begin{figure}[H]
\centering
\includegraphics[width=2.5in]{figures/mingyuan1.jpeg}
\end{figure}

地址：廣東省汕頭市東海岸新城新津片區\\
開工時間：2016年12月28日\\
竣工時間：爛尾中

\ 

這個樓盤規劃6棟，但是現在只開工3棟。這個地塊是2016年批下來的40年商業用地。現在只剩下30年。即使最後能交樓（概率不大），你也不是買下一套房，而是一個只有20年出頭的一個租約。

如果你買到這個爛尾樓，幾百萬的按揭貸款還要每個月交，但是又沒有地方住。老婆不跟別人跑才奇怪。妥妥綠帽樓盤。

這個樓盤用過的名字包括明園廣場、海灣一號、汕頭華僑試驗區、汕頭科創金融城。大家仔細甄別，避免綠帽。

\section{南昌明園九龍灣}

\begin{figure}[H]
\centering
\includegraphics[width=2.5in]{figures/mingyuan2.jpeg}
\end{figure}

地址：江西省南昌市紅谷灘區九龍湖新城\\
開工時間：2012年12月

\ 

該樓盤目前土地轉讓使用年限只剩下50多年，已經快接近商住公寓了。仍有大量存量房產積壓，無法賣出。開發商江西子公司目前欠稅未還。之前李松堅想把其中一棟整棟出售未果。除了綠帽問題之外，跟一個現金流緊張的欠稅實體交易也存在巨大風險。

\section{明園森林都市}

\begin{figure}[H]
\centering
\includegraphics[width=2.5in]{figures/mingyuan3.jpeg}
\end{figure}

\ 

地址：上海靜安大寧\\
開工時間：2004年

這個地塊在李松堅入獄前就拿了，所以土地使用年限剩下40多年，小於一些商住房。李松堅和凌菲菲一直捂盤。現在仍然有大量已經建成十幾二十年的房子以新房名義出售。銷售的時候有違法虛假網簽行為。

李松堅和凌菲菲在該樓盤違法佔用公共用地違法私建個人別墅，導致住戶喪失原本的公共用地。希望有關部門能予以拆除。

李松堅甚至違法佔用業主公用會所，給他和外圍女許潔的兒子玩樂。因為仍有部分樓房未售出，李松堅便以此為由拒絕業主成立業主委員會，阻止業主維權。希望有關部門能介入允許業主委員會成立。

注意，該樓盤其他名稱為滴翠苑、涵翠苑、疊翠苑、攬翠藝墅。最近又把老房子重新命名為「靜安·慕舍」，作為新房出售。請讀者注意自己甄別。

\section{明園小安橋}

\begin{figure}[H]
\centering
\includegraphics[width=2in]{figures/mingyuan4.jpeg}
\end{figure}

地址：上海市徐匯區中山西路1698弄\\
竣工時間：2005年

\ 

這個地塊同樣是在李松堅入獄之前就拿的，土地使用年限只有40年左右，小於一些商住房。

該樓盤竣工已經20年，其中有一棟一直未銷售，但是作為短租公寓出租過。現在李松堅和凌菲菲把這棟20年的老樓以「明園徐匯芯著」的名義重新當作新房銷售。請大家注意甄別，避免以新房價格購入超過20年樓齡的舊房。

\section{明園世紀城}

\begin{figure}[H]
\centering
\includegraphics[width=1.7in]{figures/mingyuan5.jpeg}
\end{figure}

地址：上海市徐匯區復興中路1199號\\
竣工時間：1999年12月30日

\ 

李松堅在上海的第一個樓盤。明園世紀城28樓是他和凌菲菲同住過的一套房，也就是在這裏凌菲菲背刺李松堅，給他戴綠帽，拿了明園集團一半股權養她的黃姓小孩。可以稱之為「明園元祖綠帽房」了。
