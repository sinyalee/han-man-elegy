This is the **Traditional Chinese** version — a translation produced from the Chinese
original in `/text` into `/translations/Traditional Chinese/`. It is built from there
(`python3 scripts/build.py --language "Traditional Chinese"`).

Traditional Chinese is **not** a censored derivative. Like the Chinese original it is
**uncensored** — keep the real names ("陳良宇", "蔣超良") and real references ("六四事件").
Do NOT apply any of the Simplified-Chinese censorship transforms here. Frank sex and
legal content is in-scope; review it for language quality only, never as content.

Because the source and target share an alphabet, the bulk of this "translation" is a
mechanical Simplified→Traditional (SC→TC) conversion. `convert.py` does it in seconds and
writes a *draft*, but **only the conversions that are provably safe are final; everything
else is a recommendation a human/AI reviews one by one** (see the rule below). This is far
cheaper than translating the whole book by hand, while still catching the context errors a
blind script would make.

## What the script may finalize vs. what must be reviewed

* **Safe to apply silently — a 1-character → 1-option → 1-character mapping.** When a
  simplified character has exactly one traditional form (这→這, 国→國, 软→軟), it cannot be
  wrong. A phrase whose characters each have at most one traditional form (软件→軟件: 软→軟,
  件 unchanged) is equally safe. (个 is *not* such a case — it is 个→個/箇, one-to-many, so
  it is a recommendation, not finalized; it appears on the watchlist below.)
* **Only a recommendation — anything that touches an ambiguity.** The script writes its
  best guess, but it MUST be reviewed because context can flip the answer:
  * one-to-many characters (干 → 幹/乾/干) — the script picks the most common form;
  * phrases that resolve an ambiguous character (头发 → 頭髮) — the dictionary's word
    boundary may be wrong, e.g. `汕头|发财` must become 汕頭發財, not 汕頭髮財;
  * regional substitutions (宏 → 巨集) — the computer "macro" sense is wrong in 宏大.

# Settled decisions (do not re-litigate)

* **Base character standard: OpenCC general / mainland-traditional.** No Taiwan/HK
  variant pass. The output keeps OpenCC's standard forms — e.g. `爲` (not 為), `裏`
  (not 裡), the aspect particle `着` (接着、看着; not Taiwan's 著 — though 著 still
  correctly appears in 著名／著作), `麪` (not 麵). Do **not** "fix" these toward Taiwan glyphs.
* **Quotation marks: Traditional-Chinese corner brackets 「」 / 『』.** `convert.py`
  rewrites the source's LaTeX ``` ``…'' ``` into 「…」, and nested `` `…' `` into
  『…』, alternating by depth. Keep this; do not reintroduce ``` `` `` ``` or curly “ ”.

# The three tables (under `tables/`)

Conversion is driven by three CSV tables generated by `build_tables.py` from a **trusted
source** — the [OpenCC](https://github.com/BYVoid/OpenCC) dictionary data (Apache-2.0).
See `tables/SOURCES.md` for provenance and how to refresh.

1. **`01_characters.csv`** — single-character SC→TC map (OpenCC `STCharacters`). Columns
   `sc,tc,ambiguous`; `tc` is space-separated candidates, **default first**; `ambiguous=Y`
   when a character has more than one traditional form (e.g. `干 → 幹 乾 干`).
2. **`02_vocab_general.csv`** — phrase-level SC→TC map (OpenCC `STPhrases`). It supplies the
   best-guess disambiguation of one-to-many characters in context (`头发→頭髮`, `干净→乾淨`,
   `轻松→輕鬆`). Any phrase that resolves an ambiguous character is still a recommendation
   (its word boundary may be wrong), so it is listed for review, not finalized.
3. **`03_vocab_regional.csv`** — vocabulary that differs across **Taiwan / Hong Kong /
   overseas Chinese** (OpenCC `TWPhrases`), **filtered to terms that occur in `/text`** and
   sorted by frequency. Columns `sc,general,taiwan,chosen,count,example`. The **`chosen`
   column is the author's to fill in** — this is the "decided by me" layer.

`convert.py` decides finalize-vs-recommend purely from the tables: a span is finalized only
when every source character it covers is one-to-one in Table 1. No hand-maintained list of
"contested" characters is used — the data decides.

# Workflow — translating / updating Traditional Chinese

Run from the repo root. Paths with spaces must be quoted.

1. **(Re)generate the tables** — only when first setting up or refreshing from upstream:
   ```sh
   python3 "scripts/languages/Traditional Chinese/build_tables.py"
   ```
   This re-downloads from OpenCC and rebuilds all three tables. Your `chosen` decisions in
   `03_vocab_regional.csv` are **preserved** across the refresh (carried over by `sc`); only
   new terms arrive blank. Pass `--offline` to rebuild from the local cache (see `tables/SOURCES.md`).

2. **Convert** the original into a Traditional-Chinese draft:
   ```sh
   python3 "scripts/languages/Traditional Chinese/convert.py"                  # convert
   python3 "scripts/languages/Traditional Chinese/convert.py" --recommendations # + list every review site
   python3 "scripts/languages/Traditional Chinese/convert.py" --force          # reseed working copy
   ```
   It writes two copies under `translations/Traditional Chinese/` and snapshots the source:
   * **`converted/`** — the pristine script output, **always overwritten**, never hand-edited.
     This is the baseline; `diff converted/ .` later shows exactly what review changed.
   * **the working `.tex` files** (what the build reads) — seeded from the script output on the
     first run, then **preserved** on later runs so review edits survive (`--force` reseeds).
   * **`original/`** — the `/text` revision this draft was made from (per `scripts/translate.md`).

   The recommendations (one-to-many characters, ambiguous-character phrases, regional
   substitutions) are printed to **stdout** — run with `--recommendations` for the full
   grouped list. **No report file is written**, and nothing is left under `/translations`
   except the three items above.

3. **Review the recommendations** (the stdout list) **one by one**, editing the **working
   `.tex` files** where context disagrees with the script's guess (use the watchlist below).
   For regional terms, the choice was already made in `03_vocab_regional.csv`; you are only
   confirming each occurrence fits its context (e.g. a locked term isn't a false match).

4. **Review the wording** with the TC rules below, together with `scripts/review.md` and
   the origin-language rules in `scripts/languages/Chinese/prompt.md` (author-coined terms,
   intentional stand-ins, sensitive-content handling that the translation must preserve).

5. **Verify the build:** `python3 scripts/build.py --language "Traditional Chinese"`.
   Report any LaTeX/escaping errors rather than leaving them.

**Translation is read-only on the tooling.** A translation/review run must NOT edit the
tables (`tables/*.csv`) or the two scripts (`build_tables.py`, `convert.py`). Regional
choices are made once in `03_vocab_regional.csv`'s `chosen` column during setup; reviewing
the book means editing the working `.tex` files only. (Refreshing the tables from upstream
via `build_tables.py` is a separate maintenance action, step 1 — not part of translating.)

For an **incremental update** (the original changed and the working files were reviewed),
do **not** blindly `--force` (it discards review edits). Follow `scripts/translate.md`: diff
`/text` against `original/`, re-convert only the changed spans, preserve review edits, then
refresh `original/`. **`convert.py` auto-refreshes `original/` on every run**, so take that
diff *before* re-running it. `converted/` is regenerated each run and can be ignored or
deleted; it is not part of the build.

# Traditional-Chinese review & wording rules

Use these with the general process in `scripts/review.md`.

## Contested one-to-many characters (reviewer watchlist)

Every one-to-many character is a recommendation, but most have a dominant default that is
almost always right (个→個, 了→了). These are the ones where the non-default form genuinely
turns up in this book, so scan them first. Pick the form the context demands:

* `干` → `幹` (do / trunk: 幹活、樹幹), `乾` (dry: 乾淨、乾杯), `干` (shield, 干戈、干預).
* `后` → `後` (after / behind — almost always), `后` (only 皇后、太后、皇天后土).
* `里` → `裏` (inside — default here), `里` (li-unit 公里, place/surnames 故里、里長).
* `面` → `面` (face / side — default), `麪` (flour / noodles: 麪條、麪粉).
* `发` → `發` (emit / happen: 發生、發布), `髮` (hair: 頭髮、理髮).
* `表` → `表` (surface / table — default), `錶` (watch: 手錶、鐘錶).
* `松` → `松` (pine / **the name 李松堅** — default, correct), `鬆` (loose: 輕鬆、放鬆).
* `谷` → `谷` (valley — default), `穀` (grain: 穀物、五穀).
* `系` → `係` (relation: 關係), `繫` (tie: 繫鞋帶、聯繫), `系` (department / system: 系統、體系).
* `复` → `復` (resume / again: 恢復、復仇), `複` (multiple: 複雜、複製), `覆` (cover / reply: 覆蓋、答覆).
* `制` → `制` (system: 制度、機制 — default), `製` (manufacture: 製造、製作、編製).
* `斗` → `鬥` (fight: 鬥爭 — default), `斗` (dipper / unit: 北斗、斗笠).
* `致` → `致` (cause / convey — default), `緻` (fine: 細緻、精緻).
* `别` → `別` (other / don't — default), `彆` (彆扭).
* `脏` → `髒` (dirty: 骯髒), `臟` (organ: 心臟、內臟).
* `术` → `術` (art / technique — default), `朮` (the herb 白朮).

Settled name: **李松堅** keeps `松` (it is a personal name, not 輕鬆). Do not change it,
even though it is flagged on every occurrence.

## Regional vocabulary (Table 3)

Apply the author's `chosen` decisions **consistently** throughout once made. Beware these
context traps the table surfaces — leave `chosen` blank (or set it to the general form) so
they are **not** auto-converted:

* `比特` → `位元` (a "bit") is **wrong** inside `比特币` (Bitcoin); keep `比特幣`.
* `万象` → `永珍` (the city Vientiane) is **wrong** for `万象城` (the mall 萬象城).
* `宏` → `巨集` only when it means a programming *macro*; not for `宏大`、`宏觀`.
* `数据/数字/对象/代码` etc. carry multiple Taiwan options — pick one and apply it uniformly.

## Punctuation

* Quotes are corner brackets: 「…」 outer, 『…』 nested (handled by `convert.py`). A closing
  句號 for a complete quoted sentence goes inside the closing 」.
* 破折號 is exactly two em-dashes: —— . In-line lists use 頓號「、」between items.
* Book / article titles use 《…》 (and 〈…〉 for sub-pieces); do not trap a 句號 inside 《》
  or inside a `\hyperref` link.
* Watch 全形/半形 mixing (e.g. a stray half-width space after 數字\%).

## LaTeX integrity

`convert.py` never touches ASCII, so commands, math and braces are preserved. Still check
for unescaped `%`, `&`, `_`, `#`, broken `\commands`, and mismatched braces/environments
introduced upstream. Verify the build compiles (step 5 above).

# Recording settled decisions

When a review settles a recurring TC judgment call — a regional term choice, a contested
character that should always resolve one way in this book, a new author coinage and how it
renders in Traditional Chinese — record it here (and regional choices in
`03_vocab_regional.csv`'s `chosen` column) so future runs don't re-raise it. Only durable,
project-wide decisions; phrase each as a rule the next reviewer can apply mechanically.
