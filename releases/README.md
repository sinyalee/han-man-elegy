# Book Releases

This folder contains releases of the book.

Latest SC version: [releases/人妻约会指南.pdf](releases/人妻约会指南.pdf)

[/releases/versions](releases/sc_versions) folder contains all historic versions of the book, in original Simplified Chinese, for archival purposes.

[/releases/versions](releases/en_versions) folder contains all historic versions of the English book. *Not implemented yet.*

[/releases/languages](releases/languages) folder contains all available language versions of the book.

[/releases/jiggles](releases/jiggles) folder contains some random jiggled versions of the book. These versions would have generate random hash and avoid censorship tools in WeChat and other heavily censored platforms. *Not implemented yet.*
