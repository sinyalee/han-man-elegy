# Book Releases

This folder contains releases of the book.

Only the Simplified Chinese (canonical) and English versions are published directly here at the top level; the uncensored Chinese original and every other language live under `languages/`.

Latest SC version: [releases/人妻约会指南.pdf](releases/人妻约会指南.pdf)

[/releases/cn_versions](releases/cn_versions) folder contains all historic Simplified Chinese versions of the book, for archival purposes.

[/releases/en_versions](releases/en_versions) folder contains all historic English versions of the book.

[/releases/languages](releases/languages) folder contains all available language versions of the book (including the uncensored Chinese original, as `Chinese.pdf`).

[/releases/jiggles](releases/jiggles) folder contains some random jiggled versions of the book. These versions would have generate random hash and avoid censorship tools in WeChat and other heavily censored platforms. *Not implemented yet.*
